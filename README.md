# ChelaConnect
Base inicial de ChelaConnect by Marketing Connect.

Incluye demo La Chelería, planes Básico/Premium, categorías, buscador, 15 productos, personalización por tipo de producto, carrito, cantidades, nombre, mesa, indicaciones, total y generación de pedido por WhatsApp.

La carpeta assets/images/products está preparada para agregar fotografías reales en la siguiente etapa.
